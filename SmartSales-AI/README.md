# SmartSales AI
## Retail Sales Prediction and Real-Time Big Data Analytics

SmartSales AI is an academic data analytics and machine learning project built around the UCI Online Retail transaction dataset. It demonstrates statistical analysis, regression, machine-learning-based sales prediction, and simulated streaming analytics with Apache PySpark.

## Project assessment areas

1. **Demonstration on Regression Analysis and Hypothesis Test**
2. **Execution of ML Models**
3. **Demonstration of Real-time Data Processing using Big Data Tool**
4. **Submission of Report, Presentation and Reflections**

## Dataset

- **Dataset:** UCI Online Retail
- **Repository:** https://archive.ics.uci.edu/dataset/352/online+retail
- Download the dataset from the official UCI page and follow the notebook's data-loading instructions.
- The dataset is not bundled in this repository.

## Run the project

1. Clone or download this repository.
2. Open `notebooks/SmartSales_AI_Demo_Ready.ipynb` in Google Colab or Jupyter Notebook.
3. Download the UCI Online Retail dataset from the link above.
4. Follow the notebook's setup and data-loading cells, then run the notebook from top to bottom.

## Streaming demonstration: scope

The streaming demonstration replays historical retail transactions in simulated batches. It demonstrates streaming-style processing and aggregation; it is not connected to a live retailer or production data feed.

## Reproducibility note

The executed notebook is included with its saved cell outputs. Results and charts should be interpreted from the notebook execution in the environment and dataset version used. Re-run the notebook to reproduce the analysis.

## Reports and presentation

Place the final presentation and project report in `reports/` when they are ready.
